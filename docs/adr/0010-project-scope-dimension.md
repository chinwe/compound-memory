# 项目作用域:一等 frontmatter 字段 project + 检索硬过滤,缺省 fail-closed,ns 词表扩展与打分偏好均否决

(#49 裁决,#32 提案 §4 downscoped——org/project/repo/env/branch 全层级对单机部署过度设计,单 project 维度入批)新增可选 frontmatter 字段 **`project`**:值是小写 slug(`^[a-z0-9]+(-[a-z0-9]+)*$`,复用 key 格式正则,校验单点 `storage/validation.py`);project 是**适用性**轴,与 ns 的**可见性/属主**轴正交——空(缺省)= 跨项目通用,标注后仅对应项目会话的检索面可见。**缺省 fail-closed**:检索不传 `project` 时只见 project 为空(全局)的记忆——「没声明项目 = 全局会话」,项目记忆只进对应项目会话,跨项目污染口彻底关死;存量记忆零迁移(全部无字段即全局),与私有 ns 忘带 `reader` 即拒的 fail-closed 先例同型(spec「诚实缺省」哲学)。**写侧表面**:project 是调用方上下文,与 `source`/`reader` 同型——`memory_write`/`memory_search` 与 CLI 对应动词加可选参数,宿主使用规则(SKILL.md + agent-integration.md §6)声明「本工作区 project=<slug>」,调用方 Agent 每次携带;CLI 另设 `COMPOUND_MEMORY_PROJECT` env 回退便利通道(adapter 层读、store 自身不读,与 `COMPOUND_MEMORY_AGENT_ID` 同型)——MCP server 配置在两宿主均为全局一份,按项目 env 注入无处落地,显式传参是主语义。**过滤面边界**:search 词面/向量/邻居三路候选统一过滤;get 按 id 恒可读(valid_until「get 恒可读」先例,显式寻址不受限);get 的邻居带出按读方 project 滤除(同 ns 脱敏先例,否则旁路泄漏);extraction 复述标注(`lexical_candidates`)过同套门禁;**link 不限 project**(同 ns 即可链——全局记忆 ↔ 项目记忆互链是常态,全局记忆是枢纽,邻居带出过滤兜底);蒸馏/衰减/归档/复活/stats/review 队列全部**库级不过滤**(否则项目记忆永不进蒸馏视野);**蒸馏产物继承源的 project 值**(同项目提纯);**project 不进落盘路径**(`namespaces/<ns>/<type>/<id>.md` 不变——纯元数据过滤,目录布局/索引不变量/liveness 带外探测/孤儿恢复零改动)。**私有 ns ∩ project 组合语义**:agent-* 私有记忆同样可标 project;缺省双通道(`_shared ∪ agent-<self>`)先圈可见性、project 过滤再圈适用性,两级门依次收窄。**否决的备选**:①**ns 词表扩展 `proj-*` 族**——零模型改动但结构性硬伤:缺省双通道不知道「当前项目」,项目记忆进不了缺省检索→带不出→uses=0→衰减归档,复利环断裂(解法要么改 search 多 ns 签名要么宿主双查询漏检);且 `agent-zcode ∩ project-X` 无法表达(两条轴被压扁成一条),spec「新 Agent 接入只需声明一个命名空间」的接入叙事被稀释;②**检索打分偏好**(proposal 原案「prefer the narrowest applicable scope」加权)——直接撞 spec 设计红线「先验不得翻过 sim 主序」(recall-audit 失效模式②马太效应的根治线,vec-spike S1–S4 实测复现),污染只是降权未挡住,top_k=5 槽位浪费;③**通用 tags 字段**(含 `project:` 具名维度折中形态)——适用性硬边界(不属于即挡)与相关性召回(相关即带)两种过滤语义装不下一个 list 字段:统一硬过滤会把 topic 标签变成「不匹配即不可见」,统一不过滤则防污染目标落空;具名折中是在通用字段里开语义后门,承认 project 是一等维度却拒绝给它一等字段;开放词表治理靠 LLM 自觉,同项目 slug 碎片化(`compound-memory`/`cmp-mem`)几乎必然;topic 检索正是本图 out-of-scope 的 §6/§7 地盘,通用机制会把雾变成半实现钩子。**既有事实**:项目归属此前以 `proj-*` key 前缀手工约定存在(无检索语义),一等字段是该约定的升格而非新概念。**MCP 红线维持**:恰好 5 tool 不动;search/get hit
