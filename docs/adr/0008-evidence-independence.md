# 证据独立性：宿主=源单位（记忆×宿主去重），蒸馏派生不回流源、产物证据零起点，展示归 explain

承接 ADR-0007 证据块形状后的独立性语义裁决（#32 提案 §3）：**独立性单位 = 宿主**。跨宿主对某条记忆的首次验证 +0.15（`validated_by` 按 记忆×宿主 去重，ADR-0007 沿用的机制），同宿主的多会话 / 多任务重复验证永远只有 +0.1 档——提案「independent evidence should strongly increase confidence」的落点即此：strong increase 只属于跨宿主首验。宿主身份维持 `_resolve_identity` 归一化（可选 `COMPOUND_MEMORY_AGENT_ID` attestation）；防伪不在此加码——ADR-0004 已钉死本地协作边界非安全边界。**Limitations**：宿主之间可能共享同一原始假设（如同读一篇错误文档后各自「验证」了同一错误记忆），语义级独立性在零 LLM 确定性系统内不可判定——本系统的「独立」语义即「不同宿主的直接使用证据」，宿主粒度是诚实上限而非完备保证，使用方据此理解 confidence 的含义。**派生证据不回流源**：蒸馏产物（`origin="distillation"` + `links=source_ids`，记忆级派生凭证已结构性存在）的任何 feedback 只折算产物自身，永不折算其源 S1/S2——回流即同一份证据双重计数（提案 §3 核心告诫），也即雾题「蒸馏置信度继承」的答案：**不继承**。产物证据块显式零起点 `{0, 0, 0}`——ADR-0007 的惰性迁移规则只覆盖存量旧记忆，蒸馏产物是新写记忆，继承源计数同为双重计数；产物 confidence 初值维持 distill_apply 现状（缺省 0.5 或 Agent 显式传）。**事件级不设 `derived_from` 字段**：记忆级 origin + links 已承载派生语义，feedback 签名维持 ADR-0007 形状 `(mem_id, agent, outcome)` 不再扩——证据明细里不需要第二条溯源通道。**展示边界**：独立性 / 派生语义的对外呈现（validated_by 明细、派生标记、证据来源归类）归 #44 memory explain 实施时按本决议语义字段取数；本决议只钉语义不动输出形状，search/get 的 hit 形状维持不变（MCP 返回形状红线，ADR-0006）。实施面极小：validated_by / origin / links 现状即满足语义，新增仅 distill_apply 落库时产物证据块显式零起点（不依赖缺省推断）+ 契约测试补「蒸馏产物证据不回流源」行为钉（review 队列同 key 机制与本决议正交不受影响）。Follow-ups：CONTEXT.md 新增 Independent evidence 词条、Compounding 措辞精确为「跨宿主验证（每宿主每记忆一次）」（本次已同步）；#44 explain 按 ADR-0008 取数。决议详情见 #45。
