# 遗忘语义:受控删除(文件移出 + forget 提交留痕,内容仅存 git 历史),归档不硬化,墓碑与历史改写均否决

(#47 裁决,#32 提案 §13)新终态写动词 **forget**:记忆文件从活动区/归档区物理移出(经既有 `_remover` seam,生产 `Path.unlink`),随后一条 forget 提交留痕——内容前身完整存在于 git 历史,活动库不再有本体。get / search / 邻居 / 蒸馏候选天然不可见(文件已不存在),全部读路径**零改动、零过滤**;三态模型(活动/归档/不存在)的既有不变量零新增例外。否决的备选:①**frontmatter 墓碑**(`status: forgotten` 标记 + 全读路径硬排除)引入第四态——腐蚀「活动记忆必被索引」不变量(需加例外)、search/get/邻居/蒸馏/stats 四处加过滤,换来的只是系统内可逆与活动区墓碑可见——本地单用户场景误删走 git 运维足够,墓碑的可见性由那条 forget 提交承担(墓碑即提交,不留活动区文件);②**归档终态化**混淆「暂不检索」(archive,可逆、证据导向复活)与「不再信任」(forget,终态)两个不同概念,且破坏 decay 扫描 / review-resolve 归档 / ADR-0007 obsolete 通道的既有语义,需部分推翻 ADR-0007——遗忘的终态性由独立动词承担,归档语义零改动;③**历史改写**从来不是系统动词选项——与 ADR-0006「git 历史即审计史」正面冲突并破坏 commit-hash 稳定性,privacy-gate.md 已把历史清理列为「破坏性,另行决策」的运维,不随 forget 提供。**签名与门禁**:`MemoryStore.forget(mem_id, agent, reason=None)` + CLI `forget <id> --agent <name> [--reason <text>]`;MCP 恰好 5 tool 红线不动(forget 仅 CLI + store 层,宿主 Agent 暂无遗忘通道是接受的成本——低频治理动作,CLI 足够,未来需要时再议)。按 id 动词惯例:返回恒含 `found` 键,命中返回删除前快照(`found: True`),不存在/已遗忘返回 `{"found": False}`(幂等)。私有 ns 仅属主可遗忘(role=agent,与 feedback 同规——防外来 agent 删他人私有记忆);「find → 门禁 → 删文件 → 清队列行 → 索引移除 → commit」全程在 `_write_lock` 内(写动词读-改-写红线自查)。`--reason` 可选,单行化限长 80 字符,进 commit 消息 `forget <id> by <agent>[: reason=<r>]`(消息模板进 ADR-0006 模板表);文档约定 reason 是动机短语、不贴记忆正文(对齐 ADR-0006 消息不含正文的隐私约束)。**归档不硬化**:feedback 自动复活归档记忆是 ADR-0007 有意引用的既有通道(新证据 = 复活理由),保持不动——被遗忘记忆文件不存在,feedback 返回 `found: False`,无复活通道,复活规则零改动。**review 队列交互**:forget 顺带清该 id 的队列行(行含正文片段而记忆本体已遗忘,幽灵行会误导后续裁决;幂等,无行跳过),复用 ReviewQueue 单一定义点的清行机制。**links 悬空容忍**:指向被遗忘记忆的 links 不摘除(全库扫描摘除是写放大;`find→None` 容错已覆盖邻居召回与蒸馏候选,死链不输出,内部留痕反而有审计价值);同 key 重写即全新记忆,无冲突。**恢复语义**:系统内不可逆;恢复 = 带外 git 运维(checkout/revert),系统把恢复的文件当带外新增自愈(既有 liveness 机制),不区分「恢复」与「新写入」——此诚实面写入使用文档。**stats 不加 forgotten 计数**(三态里它就是不存在;遗忘审计走 `git log -- <file>`)。**隐私边界明示**:forget 解决「活动库不再携带」,不解决「历史不再包含」——敏感内容若已入 git 历史,历史清理仍是 privacy-gate 另行决策的破坏性运维,不随 forget 动词提供。实施面:敏感区 TDD(storage/lifecycle 新动词 + review 清行,契约测试钉 found 语义/门禁/消息模板);spec 生命周期状态机段加 forget 终态分支、「防通胀(不物理删除)」表述更新为「归档不物理删除,forget 是唯一受控物理移除、内容仅存 git 历史」;CONTEXT.md 新增 Forget 词条(本次已同步);SKILL.md 与 docs/agent-integration.md CLI 命令表同步;ADR-0006 commit 消息模板表加 forget 行。决议详情见 #47。
